# Galaxy Gesture Interface 🌌✋

An interactive 3D particle system built with **Three.js** that reacts in real-time to hand gestures using **Google MediaPipe Hands**. Users can manipulate cosmic shapes (Nebula Flower, Saturn Ring System, Pulsar Heart, and Singularity Sphere) directly through webcam hand tracking.

---

## ✨ Features
- **Real-Time Hand Tracking:** Powered by MediaPipe Hands to detect gestures (Pinch, Point, Fist).
- **Interactive 3D Particles:** 12,000 dynamic particles rendered using Three.js with additive blending.
- **Cosmic Morphs:** Smoothly morphs particle formations between:
  - 🌸 **Nebula Flower** (Default/Open Hand)
  - 🪐 **Ring System (Saturn)** (Pointing Gesture)
  - ❤️ **Pulsar Heart** (Pinch Gesture)
  - 🔵 **Singularity Sphere** (Fist Gesture)
- **Glassmorphism HUD:** Sleek sci-fi telemetry overlay with live depth tracking and status indicators.

---

## 🛠️ Tech Stack
- **HTML5 / CSS3** (Custom glassmorphism UI & layout)
- **JavaScript (ES6+)**
- [Three.js](https://threejs.org/) (3D Graphics & Particle Rendering)
- [MediaPipe Hands](https://developers.google.com/mediapipe) (Computer Vision & Gesture Recognition)

## 🚀 Getting Started

No complex build steps or installations are required! Because this project uses CDN links for all libraries, you can run it instantly in any modern browser.

### Prerequisites
- A modern web browser (Chrome, Firefox, Edge, Safari).
- A working webcam.
